# BacSelect

**Bacterial genome diversity, at the scale you need.**

BacSelect is a public resource for deterministic selection of compact bacterial genome panels that span genome architecture without hand-picking organisms by name, clinical importance or expected tool performance.

This repository hosts the BacSelect website at <https://bacselect.github.io/>.

## Current status

Selector-v1 validation is complete. OPS is the frozen production selector for selector v1.0.0, and the official selector-v1 reference panels are published here at N=10, 20, 50, 100, 200 and 500. Any custom N from 10–500 is the exact prefix of the same verified ladder. These reference panels are not a dated monthly BacSelect release; the first independently versioned monthly source-universe release remains pending.

The initial design grew from a practical bacterial-genome benchmarking problem. Its frozen development universe contained:

- 55,306 eligible genomes;
- 13,765 species groups; and
- 12 sequence-derived structural features.

These figures are foundation/provenance values, not a BacSelect release.

## Deployment

The `pages.yml` workflow deploys the repository root to GitHub Pages on pushes to `main`. The repository must be named `bacselect.github.io` under the GitHub organisation/user `BacSelect` to resolve at <https://bacselect.github.io/>.

## Scientific boundary

BacSelect provides identity-blind, deterministic, diversity-seeking selection across bacterial genome architecture. It is not described as an unbiased sample of bacterial life. The selector-v1 reference panels are now published; dated monthly releases remain a separate production series with independently versioned source universes.

## Selector v1 reference panel

The site distinguishes the frozen selector-v1 reference panel from dated monthly BacSelect releases. The reference panel is selector `OPS`, selector version `1.0.0`, architecture schema `1`, with supported N from 10–500 as exact prefixes of the same verified ladder.

The validated accession artifacts are generated by the scientific repository outside Git. To publish the already-frozen artifacts into this static website checkout, run:

```bash
python3 tools/import-selector-v1-reference-panels.py
```

The importer validates the exact frozen SHA256 and byte size of all 11 official reference-panel artifacts before copying anything. It never assigns a `YYYY.MM` monthly release identity.
