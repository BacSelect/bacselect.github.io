The idea

Choose the scale.
BacSelect does the selection.

Benchmarking a tool should not require weeks of manually deciding which bacterial genomes to include. BacSelect turns that selection problem into a reproducible resource.

01

Choose your scale

Pick a tractable panel size for your compute budget or analysis. The same release and N always return the same panel.

02

Span genome architecture

Selection is driven by sequence-derived structural features rather than species popularity, pathogen status or biological importance.

03

Download and reproduce

Every released panel will carry accessions, structural features, selection provenance, checksums and an immutable release identifier.

Selection principle

Not random.
Not hand-picked.

BacSelect is designed around identity-blind, deterministic, diversity-seeking selection.

The aim is specific: build compact panels that span observed bacterial genome architecture, while controlling the influence of species that are heavily represented in the public archive.

Organism name, pathogen status, clinical relevance, publication history and expected software performance are not selection variables.

01

Define the universe

Start from a versioned collection of eligible public complete bacterial genome assemblies. The exact source snapshot and eligibility rules belong to the release provenance.

02

Describe architecture

Represent each eligible genome using sequence-derived structural features such as genome size, GC content, replicon structure and repeat architecture.

03

Control species abundance

Construct the feature geometry so that species with thousands of deposited genomes do not automatically dominate species represented by only a few.

04

Select deterministically

For a fixed release, selector version and panel size, the same inputs produce the same ordered result. Selection does not depend on organism identity.

What BacSelect does not claim

BacSelect does not represent all bacterial life. Its source universe reflects what has been sampled, sequenced, assembled to completion and deposited in the public archive. BacSelect reduces arbitrary selection within that defined universe; it cannot remove biases already present in the underlying data.

Methods & tooling

Public complete bacterial assemblies are sourced from INSDC/GenBank through NCBI Datasets. BacSelect selection and validation are implemented in Python using NumPy and SciPy. The current development foundation uses structural features generated for Project Finch. Exact software versions, environments and checksums are recorded in the scientific repository.

Where this came from
“We need a manageable set of bacterial genomes. Which ones?”

BacSelect grew out of the source-genome selection problem in Project Finch, where more than 55,000 complete bacterial assemblies had to be reduced to a small benchmark panel before assembler performance was observed.
